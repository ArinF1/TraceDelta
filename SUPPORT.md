# Support

TraceDelta is experimental open-source software. Community support is provided on a best-effort basis; there is no guaranteed response time, service-level agreement, or commercial support channel.

## Getting help

Before opening an issue:

1. Read the [`README.md`](README.md), [`docs/cli-spec.md`](docs/cli-spec.md), and [`docs/current-state.md`](docs/current-state.md).
2. Confirm the behavior is not an intentional limitation tracked in [`docs/tasks.md`](docs/tasks.md).
3. Reproduce the problem with the latest default branch and a synthetic, sanitized fixture.
4. Run `make check` and record the relevant command output.

Use the structured bug report for reproducible defects and the feature request form for proposed behavior. Keep each issue focused on one problem.

## Data safety

Do not post credentials, personal data, internal infrastructure details, or raw production traces. Replace sensitive values and reproduce problems with synthetic data. Public issue content may be retained and indexed even after editing.

## Security issues

Potential vulnerabilities must be reported privately according to [`SECURITY.md`](SECURITY.md), not through public support channels.

## Scope

Maintainers may close requests that cannot be reproduced, fall outside the documented product scope, lack enough information, or concern unsupported third-party environments. Clear reproduction steps and small fixtures make help much more likely.
